# SOC Analyst Home Lab Setup

This project demonstrates a basic SOC home lab using three virtual machines:

- Kali Linux – Security testing and network analysis
- Windows 10 – Endpoint monitoring and security events
- Ubuntu Linux – Linux monitoring and log analysis

## Objective

To gain hands-on experience with cybersecurity, security monitoring, log analysis, and SOC Analyst fundamentals.

## Tools

Kali Linux | Windows 10 | Ubuntu Linux | Virtual Machines | Networking

## Future Scope

SIEM implementation, centralized log collection, alert monitoring, and incident response.
